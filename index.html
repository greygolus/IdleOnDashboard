How IdleOn Dashboard Works

Tools

Open the main IdleOn tools from the cards. Use Compact when you want more tools and saved links visible at once.

Controls

Star favorites, open tools from their icon, move tools with arrows, and hide/show tool cards with the eye button.

Saved Links

Add personal links directly. For community sheets, use Manage, open the original, make your own copy, then paste your copy link.

Toolbox Data

Enter a public Toolbox username and Check Profile. The dashboard uses the latest public Toolbox upload, not live game data.

Current Intel

Weekly Battle, Lab Rotation, Exotic Market, and weekly tasks follow the weekly server reset. Events can refresh from profile data.

Checklist

Current Goals are one-time goals, Daily resets at your chosen time, and Weekly resets with the weekly server reset.

Saved Links Menu

Browse community sheets, add your copied sheet links, edit custom links, and restore hidden presets.
